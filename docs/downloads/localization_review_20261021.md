本轮完成官方定位/图像索引和已有结构元数据的收集与网站接入；未重新排名、未训练模型、未预测结构、未删除候选。**图像收集和自动描述分类不等于逐图人工定位确认。**

## 1. L1只有二十多个的原因

|名单|历史L1|历史L2|历史L3|历史L0|
|---|---:|---:|---:|---:|
|全716|46|352|239|79|
|最新保留497|21|238|166|72|

历史L1=原冻结记录里HPA Enhanced/Supported的核相关标注，或同一UniProt定位条目中有ECO:0000269；L2主要为HPA Approved；L3含推断/衍生来源；L0是历史未解决。它是来源规则，不是“属于核蛋白的概率”，也没有区分核为主定位、附加定位、穿梭或核膜。强证据分层会受已有研究充分程度影响，不能据此说497中只有21个核蛋白。

最初总表确实含tier 1–4、HPA定位/可靠性、COMPARTMENTS证据和带ECO码的UniProt定位。**原始字段可以逐基因作为证据使用，但tier数字不能直接替代L1–L3或当作定位置信概率。**精确HGNC联接找回716中的530个基因的源行；其余主要来自后来扩展来源，原表没有相应可确认行。

明确反例：ANHX原tier1，但原定位只有UniProt规则推断ECO:0000255及COMPARTMENTS IBA；C1orf52原tier4，却有HPA Enhanced核质定位。ACOXL历史L1也同时标注胞质和核仁，不能自动称主要核内。因此不能简单“把原tier1全升级，tier4全降级”。原表tier语义的生成代码未在已授权冻结副本中找到，不猜其完整定义；原值和来源断言已一并展示。

THAP6是另一个例子：本轮官方HPA记录主要定位为centrosome，附加为nucleoplasm；有核内观察不等于严格核内主定位。该例提示要审查主/附加位置与具体抗体、细胞系，而不只搜索Nucleus字符串。

## 2. Zinc finger候选为什么少

固定9903范围内有508个**符号以ZNF开头**的基因（不是所有含锌指的蛋白）。333个属于本轮Pharos Tdark；494个在缓存中存在FUNCTION段；只有11个进入716注释稀疏候选池，其中9个在最新497名单。

此前偏向“FUNCTION缺失/缺乏明确实验码功能”的候选定义会排除许多已有“DNA结合/转录调控”等一般描述、但具体靶点和机制仍可能未知的蛋白。**候选缺席与定位不合格是两个原因，不能归咎于L1门槛，也不能把通用家族描述当作机制已经阐明。**相反，若已知旁系成员已经解释了拟研究机制，只有同源支持也不足以形成高优先级的新机制项目。

本轮提供508个ZNF的原始FUNCTION、Pharos状态、定位层、源tier和名单去向表；没有静默扩大716或497。下一轮建议在既有9903范围内重新区分“通用能力已知”和“目标机制已知”，然后形成新候选版本。

## 4. 下一轮评分草案：等待讨论，尚未执行

建议先按核定位证据形成**主候选、混合/条件核定位备选、待补证队列**，然后分别排名，而不是把所有不确定性压成同一个分数。主要核内位置需要成员级证据；核膜/核孔与核质/染色质分开记录；混合和穿梭蛋白不写成生物学阴性。

|评分项|建议权重|具体含义|主要防偏差措施|
|---|---:|---|---|
|核定位支持与核内适配|25|核内主定位、成员级实验、图像/定位一致性、核膜/核质区分|主/附加和可靠性分开；来源去重；未知不填0；冲突列待审|
|表观遗传/染色质关联|35|染色质写入/擦除/读取、核小体/染色质重塑、相关复合物的具体实验关联；DNA修复/复制为另列基因组背景|同时看相关伙伴比例、数量和研究背景；相同PPI度/检测条件的背景对照，不按总伙伴数直接加分；转录因子或DNA结合不全部等价为表观遗传|
|关联证据可靠性|20|成员身份清楚、实验类型、源论文、可比较背景及来源独立性|二元/捕获/近邻分开；数据库重复不加独立分；高通量单研究不能冒充多次验证|
|机制新颖机会|15|目标成员与近缘已知成员之间仍未被解释的具体机制差异|不按PubMed少或FUNCTION空直接奖励；已知同源机制降优先级；未系统查文献标未评|
|实验便利性|5|适合常规生化的大小、构建和表达条件|宽平台、两端平滑小幅惩罚，最多影响5分；不硬删长/短蛋白，不按结构置信低惩罚IDR|

以上是**研究优先级草案，不是准确率、阳性发现率或校准置信概率**。大小的候选平台区间可先讨论100–1000 aa；这只是实验便利性偏好，不是功能正确性的生物阈值。完整分量、缺失掩码和敏感性结果都应保留。改变大小权重或平台区间后应检查前列名单是否稳定，并按蛋白长度、研究量、PPI度、模态覆盖分层报告。

针对非核/代谢/骨架/纤毛/膜表面为主的PPI，优先依据**候选自身定位**与**有证据伙伴的整体构成**决定主/备队列。一个代谢或骨架伙伴不能直接否定核功能；没有已知核伙伴而数据很稀疏时属于证据不足，不是明确反证。许多已知核蛋白也跨细胞区室工作，必须避免简单关键词硬删。

## 5. 同家族只选一个的实现建议

把“单蛋白科学证据”与“本次实验组合是否重复”分开：先得到可解释的单蛋白分量，再对真正高冗余组选择一个代表，其余保留在同组备选。网页81个家族/结构组包含广义结构类别，不能直接作为81个去重单元。

暂拟高冗余组需要：高双侧全长覆盖的序列相似、兼容的结构域架构、全长或关键区间结构支持，再看定位/互作背景是否一致。仅共享锌指/ANK等常见结构域不够。具体identity/双侧覆盖阈值要以实际分布和敏感性决定，不从局部结构匹配直接宣布功能冗余。FAM156A/B等相同序列还需优先解决基因特异实验可区分性。

若近缘成员已有人类成员级机制研究，而本候选没有额外背景/特异关联，不把“重复已知同源机制”作为主选；若只有泛家族能力已知、或本成员有不同伙伴/组织/定位和可区分假说，单独保留。只做一个代表可能受旁系补偿影响，不能保证单敲除会有表型，也不应把补偿性阴性解释为无功能。
