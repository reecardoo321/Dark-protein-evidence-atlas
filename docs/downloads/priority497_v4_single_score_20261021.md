## 4. 分量定义

- **定位 25**：主定位区室权重 × 附加定位排他因子 × 来源一致性；Enhanced/Supported/Approved 不再改变点位，只改变区间；Uncertain/多基因才降权或未评估。
- **染色质相近度 35**：A=Σ枢纽权重×参照权重（专门1、广泛0.25），T=Σ枢纽权重；p_adj=(A+0.5)/(T+2.5)；purity=min(1,p_adj/0.5)；z=(A−p0T)/sqrt(p0(1−p0)T)；enrich=clip(z/4)；support=1−exp(−A/1.2)；diversity=min(1,程序数/3)；chrom=purity×(0.25+0.75support)×(0.85+0.15diversity)+0.10enrich。
- **可靠性 20**：0.5×前3边平均质量 + 0.2×程序数/3 + 0.2×有效伙伴数/3 + 0.1×是否有明确背景；共享序列封顶0.5。
- **功能未知度 15**：own 0.05 / family 0.20 / 否则0.20+0.45×clip((0.6−r)/0.4) / 无近缘0.65；未知按中性0.5展示但保留0–1区间；PubMed 不直接奖励。
- **结构大小/实验便利 5**：min(1,L/100,1000/L)；100–1000aa 满分，不硬删长短蛋白。
- **聚合**：base=Σ权重×分量（定位/染色质/可靠性缺失按0；功能未知按0.5）；coverage=(已评估的定位/染色质/可靠性权重+15+5)/100；score=base×(0.6+0.4×coverage)。覆盖度只反映证据缺失，不惩罚未知功能。
